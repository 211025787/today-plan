# 2026-10-30

## 防烧屏（OLED burn-in）改造

- 新增 `ui/common/AntiBurnIn.kt`：
  - `Modifier.antiBurnInDrift(active, range=6dp)`：两个异周期无限往返动画（17s/23s，LinearEasing）组合成李萨如漂移，用 `Modifier.offset {}` 仅改放置位置；未激活时直接返回 this，避免无谓动画帧。
  - `AntiBurnInGlow(alpha=0.10)`：三个低透明度径向渐变光斑沿椭圆轨迹 24s 循环游走，整屏像素持续微变。
- FocusScreen：计时中（running 且 phase != IDLE）内容加 drift；白噪音静音时叠加 AntiBurnInGlow（有声时已有 AmbientBackground）。
- CalendarHomeScreen：`anyPlanRunning = state.timers.values.any { it.running }`；月历 Column 与日页面 Box 加 drift，日页面叠加 glow。
- MainActivity.AppScaffold：番茄/计划计时中 Dock 自动隐藏（5s 后），任何按下（PointerEventPass.Initial 旁听不消费）唤出并重新计时；Dock 用 AnimatedVisibility 淡入滑出。

## 专注页动画重做 + 多样提示音

- GitHub 调研：候选 `jaimebg/Ambio`（MIT，Compose 专注计时器，带 CC0/自合成音频，ATTRIBUTION.md 记录来源）；但沙箱内 bash 网络被拦截（curl HTTP 000），无法下载音频二进制。
- 因此提示音改为**本地程序化合成**（Python 标准库 wave+math，脚本在 `.tmp_sounds/gen_chimes.py`），生成 5 个 WAV 到 `app/src/main/res/raw/`：chime_bell（清脆铃）/ chime_wood（木鱼）/ chime_drop（水滴）/ chime_bowl（颂钵）/ chime_soft（柔音），共约 1MB，无第三方素材版权问题。
- 新增 `ui/common/ChimePlayer.kt`：SoundPool 预加载 + 播放，options 列表含 key/名称/emoji；FocusListApp.onCreate 预热。
- SettingsStore 新增 chimeType（默认 BELL）+ updateChime；FocusTimerService/PlanTimerService 改用 ChimePlayer（不再用系统默认通知铃声）。
- 专注页设置面板新增"提示音"区：FilterChip 横向选择，点击即试听并保存。
- 新增 `ui/focus/FocusAura.kt` 替代原粒子/波浪背景：`TimerAura` 唱片式光环（42 圈长短交错同心弧 + 26s 自转 + 反向扫光 + 7s 呼吸缩放）套在计时环外；`FocusBackdrop` 全屏底光按白噪音模式区分（静音=蓝紫柔光 / 白噪=冷蓝+光尘 / 棕噪=暖琥珀+底部声浪）。
- 专注页底部控件重设计：88dp 圆形主按钮（播放/暂停/继续）+ 次要文字按钮（选择计划/放弃本轮/跳过休息）；加 navigationBarsPadding + 96dp 底部留白，内容改为「居中优先、小屏可滚动」，光环 420→340dp。
- 修复防烧屏漂移「开始时瞬移左上角」：原实现用两条 infiniteRepeatable 往返动画，初值 0 导致激活瞬间 offset=(-6dp,-6dp)。改为 `Animatable<Offset>` 从 (0,0) 出发、黄金角步进目标点、每段 11s 匀速；LaunchedEffect(active) 暂停时取消动画冻结当前位置，恢复时从冻结点续跑，全程无跳变。
