## 胶囊服务路径不显示的根因：线程

- 现象：设置页预览胶囊正常，但计划计时中退出应用无胶囊。
- 根因：预览在主线程（LaunchedEffect）调用 `TimerCapsule.show` → `WindowManager.addView` 成功；PlanTimerService 在 Dispatchers.Default 协程（无 Looper）调用 → ViewRootImpl 要求带 Looper 的线程，addView 抛异常被 catch 静默吞掉。
- 修复：TimerCapsule 内部用 `Handler(Looper.getMainLooper())`，show/hide 统一 post 到主线程执行。
- 版本 1.0.36 已出包验证。教训：**系统悬浮窗/View 操作永远 post 主线程，Service 后台协程也不例外**。

## 胶囊拖动乱飞修复

- 根因：ACTION_MOVE 里用 `lp.x + (rawX - downRawX)`，而 lp.x 每次 MOVE 都被改过，等于把累计位移反复相加 → 指数漂移。
- 修复：ACTION_DOWN 记录 `startX = lp.x`，MOVE 用 `lp.x = startX + (rawX - downRawX)` 绝对偏移计算，再 clamp。
- 版本 1.0.42 已出包。教训：**拖动位移必须基于按下时的基准坐标，不能用被持续修改的当前坐标做增量累加**。

## 胶囊闪烁 / 拖动丢失修复

- 根因：showInternal 里 `lastConfig != config` 就把窗口 remove + add 重建；而拖动后位置持久化会改变 config（xPx/yPx），下一秒就重建 → 闪一下，且触摸事件绑在旧 view 上，拖动被打断（表现为不跟手）。
- 修复：拆出 `styleChanged()` 只比较外观字段（不含坐标）；外观变化走 `applyStyle` 就地更新（背景 drawable、文字/圆点/进度条颜色、行高、窗口宽度），仅行数变化才重建窗口；引入 posFromPersist 处理「重置位置」。
