## 🔑 高德 Key 显式保存 + 成长组改成计划维度（v1.0.89）

用户反馈：①「设置页的地图 key 输入后都没有保存，我都不知道存了没有，要有编辑和确定」；②「成长里的都是统计专注的，要改成统计日历内的计划，不应该是专注」。第 ② 点问了范围但用户跳过选择，按最稳妥方案落地（新增计划维度的统计页，专注统计保留但降级分组）。

### ① 地图 Key：编辑 / 确定
- 原来是 `onValueChange` 里直接 `travelPrefs.amapKey = it`（边打字边存，没有回执）。
- 改成 `savedKey`（已落盘）/ `draft`（草稿）/ `editing`（只读态 vs 编辑态）/ `savedJustNow` 四个状态：只读态打码展示（`••••••••3f2a`）+「编辑」；编辑态 OutlinedTextField +「取消」「确定」，只有点确定才写盘并回显「✓ 已保存，下次搜索立即生效」；留空确定 = 「清空并保存」。

### ② 计划维度统计
- 关键判断：整个 StatsScreen / MonthReview / Achievements 的数据源是 `FocusRepository`（番茄记录），而日历计划的时间在 `plan_logs`。用户要的是后者，所以**另起一条统计口径**，没有硬改旧页面（否则会连带成就结算和一大批单测）。
- 新增纯 JVM 工具 `util/PlanStats.kt`：`of()` 汇总日/周/月/累计、活跃/达标天数、连续达标、逐日窗口、计划排行；`monthGrid()` 排周一起始的 6×7 月历；`level()` 五档着色；`durationText()`。**先按天累加秒再 /60**，否则多个计划各 30 秒会被逐个取整抹成 0。
- `PlanStatsTest` 13 条（673 → 686 全绿）。
- 新页面：`ui/stats/PlanStatsScreen.kt`（ViewModel combine `observeLogsBetween` + `observeAllPlans` + 每日目标；四宫格 + 本月计划日历 + 近 14 天柱 + 计划排行 + 空态）、`ui/stats/PlanReviewScreen.kt`（复用 `PlanTimelineCard` + `GraduationCard`，含归档/续期接线；GraduationCard 空态会整张不渲染，所以 `hasEnded` 要连标签一起藏）。
- 「我的」页：「成长」→ 新增主组「**日历计划**」（计划总览 / 计划节奏），原三项挪到「**专注（番茄）**」并在副标题写明口径。没有删旧页面，否则整条专注统计链会成为孤岛。
- 路由新增 `SettingsRoutes.PLAN_STATS / PLAN_REVIEW`。

### 坑
- `PlanStatsViewModel` 里不小心同时声明了 `private val monthStart` 和 `val monthStart get()` → Conflicting declarations；改成单个公开 val。
- Compose 的 `Row(verticalAlignment = ...)` 用 `Alignment.Bottom`，没有 `BottomVertically`。
- 包 1.0.89（code 178）。

### ② 手写开屏
- 新建 `ui/splash/WarmSplash.kt`：图标 spring 弹入 → 品牌名淡入 → 正文与署名逐字写出 → 淡出进主界面；轻点跳过；从通知 / 小组件直达（`ACTION_OPEN_HABITS` / `OPEN_TIMER`）不显示开屏。MainActivity 用 `Crossfade(targetState = splashVisible)` 包住 `WarmSplash` 与 `AppScaffold`，`remember { WarmQuotes.random() }` 放在 Crossfade 外 → 每次冷启动换一句。
- 手写感四层：毛笔字体 + 每字固定伪随机倾角 + `drawWithContent { clipRect(right = size.width * local) }` 从左往右揭示 + 笔尖墨点跟随；`Animatable<Float>` 以「字」为单位线性推进，46ms/字。
- **性能关键**：进度传 `() -> Float` lambda，在 `graphicsLayer {}` / `drawWithContent {}` 里延迟读取，只失效图层不重组；最初写成 `val progress = pen.value` 会让 30+ 个字每帧全量重组。
- 跳过时用 `skipped` 作为 `LaunchedEffect` 的 key，取消后台动画协程，避免淡出期间继续跑完。
- 字体：Ma Shan Zheng 毛笔楷书（Google Fonts，SIL OFL 1.1）。GitHub raw 握手失败，改走 `fastly.jsdelivr.net/gh/google/fonts@main/...` 成功；`pyftsubset --text-file` 按 `WarmQuote.kt` 里所有字符串 + 常用字子集化，5.6MB → **81KB / 140 字形**，许可文件放 `docs/OFL-MaShanZheng.txt`。fontTools 校验无缺字。
- **以后改文案必须重新子集化**（新汉字不在子集里会显示豆腐）；字符表 = `WarmQuotes.ALL` 全部正文/署名 + 「暖历— 」+ 常用标点数字。
- **内容取舍**：不杜撰真实政治/公众人物原话。12 条是为暖历写的原创短句，署名是带梗的身份泛称（某位韩国前总统 / 币圈老兵 / 青瓦台夜班人……），不含政治评价与投资建议。要换真实语录只需改 `WarmQuotes.ALL` 的 `text` / `author`（并重新子集化）。
- 坑：Git Bash 的 `/tmp` 是 Windows 临时目录，Windows 版 Python 不认 `/tmp/...`，要用 `os.environ['TEMP']` 或 `cygpath -w`。
- `WarmQuoteTest` 5 条（686 → **691 全绿**）。
