## 🔍 用户反馈五连修（v1.0.84，第 29 次迭代）

1. **搜索搜不到旅游规划**：`HomeViewModel.searchResults` 原来只 combine 计划 + 备注；新增 `TripDao.observeAllStops()` / `TripRepository.observeAllStops()`，combine 五个流（计划/备注/行程/全部站点/关键词）。行程按「标题(权重3) + 备注 + 经过的地点」排名，搜「西安」也能命中经过西安的行程；`HomeSearchHit.TripHit` + `SearchResultList.onOpenTrip` → 点结果直达 `onOpenTravel(trip.id)`。
2. **退出搜索要过渡**：`CalendarHomeScreen` 用 `Crossfade(targetState = searchActive, tween(220))` 包住搜索/日历两支，退出不再硬切。
3. **卡片页返回日历瞬间消失**：新增 `lastSelectedDay`（`LaunchedEffect(state.selectedDay)` 里记住最后一天），用 `AnimatedVisibility(visible = selectedDay != null, enter=fadeIn+expandVertically, exit=fadeOut+shrinkVertically)` 包住卡片内容；退出动画期间用 `state.selectedDay ?: lastSelectedDay` 继续绘制。
4. **导出旅游规划**：①备份 JSON 之前已含 trips/stops/legs，但漏了 `cardZ`（自由摆放的叠放顺序）→ `BackupTrip` 补字段 + collect/mapping 同步，「我的」导出说明也写上旅游规划，BackupCodecTest 增加往返断言；②新增 `Ics.forTrip` / `IcsTrip`：一个行程 = 一个覆盖整段日期的**整天事件**（不写 RRULE，DTEND 排他，描述含备注与「A → B → C」路线，无日期退化成今天），入口在行程库每条的 📅 按钮 → SAF 写 .ics。
   - 顺带修 `Ics.fold()` 的隐藏 bug：原来按 `Char` 遍历，emoji 是代理对，会被算成 1+1 字节甚至从中间切断 → 改成 `line.codePoints()` 按码点遍历。
5. **冷启动空白日历**：`HomeUiState` 增 `loaded` 标志（stateIn 初始值 false，combine 首帧置 true）；未加载时用顶层 `AnimatedVisibility` 覆盖一张与真实布局同构的**骨架屏**（标题/建议条/星期表头/6 行格子 + 呼吸动画），数据到达后 300ms 淡出。
