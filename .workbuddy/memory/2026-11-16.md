# 2026-11-16

## 今日规划：添加计划支持自定义重复日（v1.1.44）

**需求**：首页添加计划时，选完日期范围后可自定义执行日——周几（多选）/ 工作日（不含节假日）/ 休息日（含节假日），确定后只落在这些日期上。

**方案决策**：不把计划展开成多条「单日计划」，而是给 `PlanEntity` 加规则字段
`weekdaysMask`（bit0=周一…bit6=周日，0=每天）+ `dayRule`（0=按周几 / 1=仅工作日 / 2=仅休息日），
所有「某天是否生效」的判断统一走 `util/PlanSchedule.kt`。好处：一条计划改规则全局生效，统计口径天然一致。

**新增 / 改动**：
- 新建 `util/PlanSchedule.kt`：`DayRule`、`WeekdayMask`（位运算 + 文案）、`ChinaHolidays`（内置 2025–2027 国务院放假表 + 调休上班日，其余年份按周一至周五兜底）、`PlanSchedule`（isActive / countActive / activeDays / activeIndexUntil / nextActive / lastActive / describe），countActive 带 ConcurrentHashMap 缓存（键=区间+掩码+规则，上限 256）。
- `PlanEntity` + `AppDatabase` v12（`MIGRATION_11_12` 两条 ALTER，旧计划默认每天，行为不变）。
- `AddPlanSheet`：新增「重复」区（每天 / 自选周几 / 工作日 / 休息日）、7 个周几圆点、结果预览（`每周一、三、五 · 共 12 天` + 首次执行日 + 横向日期列表最多 60 个）；范围内 0 个执行日时禁用保存。
- 口径改造：`HomeViewModel.plansOfDay`、`focusPlan`（找最近执行日）、`deletePlansInRange`、`PlanRepository.observeActiveToday`（SQL 只筛区间，规则内存过滤，删掉 `PlanDao.observeActiveToday`）、`DayCardBoard`（第 N/M 天）、`PlanPaces.of`（新增 activeTotalDays / activeElapsedDays 参数，分母换成执行日）、`PlanInsightSheet` 头图文案、`PlanTimelineCard` 文案、`RangeDeleteDialog` 过滤、`Ics`（RRULE 按规则生成 `FREQ=WEEKLY;BYDAY=…`，DTSTART 取首个执行日）。
- 空态文案：日卡片无计划但区间内有计划时提示「按重复规则今天不执行」；保存后今天不是执行日会自动翻到首个执行日并提示。
- 备份：`BackupPlan` 加两字段（默认 0，旧备份兼容）。
- 单测：新增 `PlanScheduleTest` 15 条；全部 741 条通过。README 补「🔁 重复规则」章节与测试表。

**产物**：`app/build/outputs/apk/debug/app-debug.apk`（versionName 1.1.44，versionCode 打包时 353、自增到 354）。
