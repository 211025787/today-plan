## 🐟 桌宠动画 + 卡片自由摆放（v1.0.83，第 30 次迭代）

1. **桌宠为什么「根本不一样」**：
   - 旧实现用 Coil 加载 animated WebP，但工程里没有 `coil-gif`，Coil 只解第一帧——idle 截图 1 秒内像素完全不变，头像是静态的；`head_pat` 也只是换了一张静态首帧。
   - 首页 FAB 在右下角、桌宠头也在右下角：实测点 (800,1415) 会展开 FAB，根本点不到头；桌宠又被挤在 Dock 的 100dp 盒子里，只露出很小一只。
   - `HEAD_PAT` 固定 5 秒回 idle，而原版 head_pat 是 241 帧 × 42ms ≈ 10.1 秒，表情还没播完就被切走。
   - 修复：`WhaleGirlPet` 改用 Android 原生 `ImageDecoder`（API 28+）解码 `AnimatedImageDrawable`，低版本退回静态首帧；按显示尺寸 `setTargetSize` 省内存；循环/一次性动画分别设置 `repeatCount`；一次性动画按 manifest 时长回 idle。
   - 按 dafeiyu-web 的 hit() 实现分区：左右 16% 是尾巴、上方 48% 是头、其余是身体；点/拖用同一个 `awaitEachGesture`，避免轻点和拖动抢事件。头 → `head_pat` + 气泡「摸摸头～ 好舒服」，身体 → `poke`，尾巴 → `tail`，拖 → `dragging` / `dragging_release`；空闲 25–45 秒随机伸懒腰/打哈欠/吃 token。开始拖动时用 `haptic` 给反馈，气泡 1.8 秒自动消失。
   - 桌宠放大到 140dp，只在 `currentRoute == "home"` 常驻；首页 FAB 左移 144dp，不再压住头部。行程地图/专注页不再被桌宠挡。
   - 坑：`AnimatedImageDrawable` 的 `repeatCount` / `AnimatedImageDrawable.REPEAT_INFINITE` 是 API 28；`ImageDecoder.setTargetSize` 必须按 412:344 的比例传高度，传成正方形会把鲸鱼娘拉扁。

2. **卡片不再「可选」、不再自动重排**：
   - 删掉 `CardResizeDialog` 的入口（文件保留但不可达），右下角手柄改为 `detectDragGestures` 直接改大小；桌面改为 `DayCardBoard` 自由画布（4 列，x/y 持久化），不再用 `LazyVerticalGrid` 的 span 变更。
   - 数据库 v8 → v9：`plans` / `trips` 增加 `cardCols`、`cardRows`、`cardX`、`cardY`；旧数据 `cardCols/Rows=0` 时按旧 `cardSize` 兜底，`cardX/Y=-1` 时首次打开自动补位并写回，之后位置固定。
   - 长按拖动：`detectDragGesturesAfterLongPress`；长按后原地松手仍然打开原来的操作菜单（`onDragEnd` 且位移为 0），拖动才落位，`suppressClick` 防止长按松手又弹统计。
   - 不盖住邻居：移动落点用 `CardBoard.resolveMove` 找最近空格；缩放用 `maxFreeResize` 在邻居边界处停住，松手 toast「空间不够，先把旁边的卡片挪开」。`CardBoard` 纯逻辑加了 `fitsAt / resolveMove / maxFreeResize` 和 7 条单测。
   - 卡片内容改为按实际宽高 + 占列数的响应式布局（极简/横向/纵向/完整四档）：计时按钮固定右上 28dp、缩放手柄右下 44dp 命中区（视觉 20dp），内容分别为它们留 end/bottom padding；进度条也不再伸到手柄下面。1 列 1 行显示 icon + 百分比；1×2 显示标题 + 百分比 + 倒计时 + 进度 + `x / 目标 分`；大卡显示 note/pace/goal。
   - 旧 `GradientPlanCard` / `GradientTripCard` 作为死代码暂时保留（新的在 `DayCardBoard.kt`），没有删除以减少回归风险。

3. **备份 schema 4 → 5**：`BackupPlan` / `BackupTrip` 补 `cardSize/cardCols/cardRows/cardX/cardY`，`BackupTrip` 同时补 `startDate/endDate`（之前备份会丢日历日期）；导入旧备份字段走默认值。

4. **实测**（MuMu Android 12，900×1600 / 240dpi）：
   - idle 两帧像素 diff > 0（确认真的在动）；点 (770,1445) 头 → 气泡「摸摸头～ 好舒服」+ head_pat；点身体 → 「戳我干嘛～」；从 (770,1450) 拖到 (550,1200) → 桌宠跟着走、松手「呼…站稳了」。
   - 1×1 Read 向右侧拖手柄被 Run 挡住 → 不放大、toast「空间不够…」，DB 仍 1×1；Review 长按拖到 y=5 成功落库；长按原地松手打开菜单（含新提示行）。
   - 日卡片页审查各档位：Write 1×2 的 `0 / 60 分`、Stretch 1×2 的 `0 / 30 分` 不再被裁；大卡进度条不再被手柄盖住。
   - 测试 637 → **657 全绿**（新增 CardBoard 7 条；备份往返样本增加 trip/layout 字段）；Debug 包 1.0.83。

5. **遗留/说明**：
   - 模拟器里用 SQL 种了 Read/Run/Write/Code/Stretch/Review/Plan/Auto 8 条计划用于布局测试，不属于应用内置数据；正式安装不会有。
   - 桌宠位置不持久化（重启回 Dock 右侧），与演示页刷新回默认位置一致；卡片位置/尺寸持久化。
   - 手势自动化只能用 `input draganddrop` 验证长按拖动；`input swipe` 因为一开始就移动，不会进入 long-press 分支。
