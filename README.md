**暖历**是一个以离线为主的 Android 时间管理应用：以日历为入口安排跨日期计划，用秒表记录每天的真实投入，再用番茄钟与备注把「规划 → 执行 → 复盘」串起来；新增的「行程」页还能把下一趟旅行直接画在地图上。所有计划、记录与行程都只保存在本机；只有旅游规划里的地图底图与真实道路路线需要联网获取，不会上传任何个人数据。

---

## 开屏：暖历 · 一句话手写

- **每次冷启动随机**抽一条格言（`WarmQuotes`，12 条），图标弹入 → 品牌名淡入 → 正文与署名被逐字「写」出来 → 淡出进主界面；轻点任意处可跳过，从通知 / 小组件直达时不显示开屏；
- 手写感由四层叠出：**毛笔手写字体** + 每字固定的微小倾角 + 从左往右的笔迹揭示（`clipRect`）+ 笔尖墨点跟随；约 46ms 一个字，写完自动收尾；
- 字体用 **Ma Shan Zheng 毛笔楷书**（SIL OFL 1.1，许可证见 `docs/OFL-MaShanZheng.txt`），经 `pyftsubset` 按开屏文案子集化后只有 81KB，不会把 APK 撑大；
- 进度读在 `graphicsLayer` / `drawWithContent` 里（延迟读取），动画每帧只失效图层、不重组整句，30 多个字也不掉帧；
- 格言是**为暖历写的原创短句**，署名是带梗的身份泛称（某位韩国前总统 / 币圈老兵 / 夜班人……），不冒充真实人物原话、不涉及政治评价或投资建议；要换成考据过的真实语录，只改 `WarmQuotes.ALL` 里的 `text` / `author` 两个字段（新增汉字需重新子集化字体）。

## 功能一览

### 📅 日历（首页）

- **月视图**铺满屏幕，每个日期格最多显示 3 条计划：每条是迷你进度条，越接近当日目标颜色越深，行尾显示完成率数值；
- **左右滑动翻页**，跟手移动 + 惯性吸附，预渲染相邻月减少卡顿；滑动过程中点击不会误触日期格，松手后才响应；
- **点某一天**进入当日卡片页：渐变方卡、右上角开始/暂停秒表、**点卡片看这个计划的投入统计**、长按菜单（投入统计 / 补录时长 / 存为模板 / 删除）、「管理」多选批量删除；
- **按日期范围删除**（右上角功能菜单 → 🗑️ 删除计划）：只移除区间内的部分，范围外日期自动保留（覆盖中间时计划会被拆成前后两段）；
- 格子高度自适应屏幕，底部自动避开系统导航条与悬浮 Dock。
- **右上角功能菜单**：渐变圆形按钮（Apps 网格图标，非加号），点击向下展开玻璃胶囊菜单，含 ⚡ 一句话建计划、📋 添加计划、📝 备注、🧳 添加旅游规划、🗑️ 删除计划五个入口；菜单接近不透明保证可读，整行均可点击；
- **文字永远可读**：进度填充调淡到 28% 不透明度，标题与完成率数字统一深色——任何计划色下都读得清，也不再出现黑白混杂。
- **不再闪空白**：冷启动首帧数据没到时显示与真实布局同构的**骨架屏**（标题 / 建议条 / 星期表头 / 6 行格子，缓慢呼吸），数据到达后淡出；
- **进出卡片页是对称的，而且跟手**：点某一天，日历纵向收起、卡片页从下方顶上来；返回时日历展开、卡片被原样挤回去（进出走同一条曲线）。接了 Android 的**预测式返回**：从屏幕边缘往里滑时，`PredictiveBackHandler` 的 progress 直接映射成收展比例（`BACK_FOLLOW = 0.5f`，即滑到系统允许的最大距离时动画走一半），松手完成手势就是返回，中途放弃则弹回卡片页；两块内容都按整屏高测量、只裁掉看不见的部分，所以过程中不会把日历「压扁」。
- **性能**：收展比例在测量/绘制阶段读取（`Modifier.layout` + `graphicsLayer`），手势每帧只重跑布局和绘制，不触发重组。
- **卡片自由摆放**：长按卡片拖到任意位置，松手吸附到最近空格；右下角是一个更大的白色圆角角标，**按住直接拖**，拖动中卡片宽高实时跟手，松手才吸附到 `1×1 / 1×2 / 2×1 / 2×2 / 1×3 / 3×1` 六种规格；缩放时若旁边有卡会临时盖住，松手后该卡置顶（重开也保持），长按可挪开。位置与大小写入数据库，之后不会再自动重排。卡片内容按实际宽高自适应，计时按钮和缩放手柄都有独立留白，不会压住文字。

### 🗺 旅游规划：把下一趟旅行画在地图上

Dock 新增第五个入口「**行程**」：全屏地图 + 顶部搜索 + 底部横向行程条，搜索、停留、交通、连线一次排完。

- **搜索位置**：内置约 250 个常用目的地（城市 / 古镇 / 景区 / 海岛 / 境外热门），按名称、别名、省份即时搜索，输入「成都市」也能命中；也可以直接**长按地图任意位置**落点，或点搜索条右侧的图钉进入「点地图选点」模式；
- **停留时长**：每一站都能设置待多久（1 小时 / 半天 / 1 天 / 一周等快捷项 + 分钟级加减），地图上的地点标签直接显示「成都 · 2 天」；
- **选择行程方式**：站与站之间选飞机、高铁、火车、大巴、公交、地铁、自驾、邮轮、骑行、步行或其他，共 11 种；
- **站点 / 线路按方式收集**：
  - 飞机 / 高铁 / 火车 / 大巴 / 邮轮：出发与到达站点（机场 / 车站 / 港口，带常用站点建议）+ 航班号 / 车次 / 班次；
  - 公交：填写公交线路（如 `302 路`），并可保留上车站 / 下车站；
  - 地铁：按城市列出线路，多选并记录换乘顺序（`1号线 → 2号线 → 4号线`），没有收录的城市可自己添加线路名；
- **真实路线 vs 弧线示意**：公交、大巴、自驾、骑行、步行会向 OSRM 请求**真实道路折线**，地图沿着街道画；飞机、高铁、火车、地铁、邮轮没有公开轨迹，用不同弧度的平滑弧线表示（飞机弧度最大、步行几乎笔直），一眼能分出「飞的」还是「走的」；
- **线上标注**：上一站与下一站一定有线相连，线中间是一枚「方式 + 时长」标签（`🚄 高铁 4 小时 30 分`）；没填时长的段显示「时长待定」，缺失的段用灰色虚线提示去补；
- **地点标注**：编号圆标 + 「名称 · 停留」，点圆标或下面的标签都能打开编辑；
- **行程单**：底部「行程单」按「站点 → 交通 → 站点」竖排展开，列出每段的站点 / 车次 / 地铁换乘 / 里程，顶部汇总「停留 / 在路上 / 里程」与约几天（天数取停留天数与在途天数的较大值：2 天停留 + 1 小时车程仍是 2 天，30 小时火车才会跨天）；
- **多条行程 + 模板**：行程库可新建、改名、换封面色、删除；内置「川西小环线 / 江南水乡 / 云南慢行 / 关西漫步」四条模板，点一下生成带地点的完整行程，再按自己的节奏改；
- **坐标对齐**：底图用高德瓦片（GCJ-02），内置地点与 OSRM 轨迹是 WGS-84，绘制前自动纠偏，境内不会整体偏 500 米；境外坐标原样使用；
- **离线也不散架**：底图没加载时显示纸面网格与「底图需联网」提示，行程与路线仍可编辑；联网后进入行程会自动补真实路线并缓存进数据库，之后断网也能看到上次的折线。
- **边缘滑动跟手返回**：地图主页接了 Android **预测式返回**，`progress` 1:1 映射成**整页水平右移的距离**——页面宽高完全不变，不缩放、不淡出、不圆角；滑多少就向右移多少，左边同步露出「上一页」（与日历主页同构的静态预览：月份标题 / 建议条 / 星期表头 / 6×7 格子 / 底部 Dock，带轻微视差）。滑到最大时当前页整页移出、上一页完全显示，松手即返回，中途放弃弹回原位。进度在 `graphicsLayer` 里延迟读取，手势每帧只改图层、不重组整张地图；有弹层或选点态时返回键先收起最上层，不会一下退出地图页。

### 🧭 「现在」建议条：此刻最值得做的那件事

- 日历上方常驻**一条**建议，不外挂弹窗、不打断操作：图标 + 一句话 + 底部细进度线；
- 六种判断按优先级给出**唯一**答案：今天没有计划 ✨ → 正在计时 ⏱ → 全部达标 ✅ → 深夜收工 🌙 → 全新开始 ▶ → 最接近达标 🎯；
- **先易后难**：多条计划都没达标时，挑「离达标最近」的那个（`再 5 分钟达成「读书」`），先拿到正反馈再谈别的；
- **点一下就开工**：右侧「开始」胶囊直接启动该计划的秒表；没有计划时点开 **⚡ 一句话建计划**；其余情况点进今天的卡片页；
- **不制造焦虑**：22:30 之后若还没做完，话术换成「今天先到这里，明天补上，别熬夜」，不再催进度；
- 时钟每分钟刷新一次，「夜深了」这类建议会自己切换，不需要手动刷新。

### 🗓 周条：在日卡片里横向翻日子

- 当日卡片顶部有一条**周条**：周一到周日 7 个圆点，星期在上、几号在下；
- 圆点就是**迷你热力图**：浅色=动过、中色=过半、实心主色=达标，没有记录的日子几乎透明，不抢眼；
- **点一下切那天**，不用先「返回日历 → 找格子 → 再点进去」；跨月的那一周会自动把月历翻到对应月份（顺带修掉了搜索跳转后月历与数据不同步的问题）；
- 左右箭头**整周前后翻**：看上周怎么练的、把下周提前安排一眼，两下就到；
- 底部一句本周小结：`本周 3/4 天达标 · 4 小时 20 分`——分母是**已过的天数**（含今天），周一不会一上来就说「0/7 天达标」；整周都在未来时改说「这一周还没有开始，已安排 2 天」；
- 数据按周单独取一次（`weekLogs`），跨月的那几天数字也准，不会因为不在当月网格里变成 0。

### 🌙 收工小结：给一天一个结束的动作

- 当日卡片右上角会出现「**收工**」——只在**还有计时在跑**或 **21:00 之后**露面，白天不打扰；
- 点开是一张今日小结：总时长、达标 x/y、逐计划投入（按分钟从多到少排，最多列 5 个）；
- **一键暂停全部计时**：并行秒表原本只能一个个停，忘记停表会把第二天的时间一起算进去，这里一次收尾；
- 暂停后弹层不关，会立刻看到「计时中」消失、达标数更新；
- 结语按情况换：全部达标「可以安心收工了」、晚上「今天先到这里，明天继续」、白天「「读书」还差 10 分钟，或者就到这儿」；
- 旁边还有「写一句今天」，直接跳到当日备注——把结束动作和复盘连在一起；
- **存进备注**：一键把小结写成当天的一则 Markdown 备注（标题固定为「收工小结」），内容形如：

  ```markdown
  ### 收工小结 · 11 月 1 日
  **今天 2 小时 10 分** · 达标 3/4

  - 写作 60 / 30 分钟 ✅
  - 读书 40 / 30 分钟 ✅
  - 健身 10 / 30 分钟

  > 「健身」还差 20 分钟，或者就到这儿
  ```

  同一天再打开会显示「已存进备注 ✓」并禁用，不会写进第二条；想改就点开备注自己补两句。

### ⏱ 计划与秒表

- 计划是**跨日期区间的实体**（起始日 ~ 截止日 + 每日目标时长），不是单日任务；
- 支持**多个计划并行计时**，暂停只冻结不清零，再点继续接着累加；
- 基于 wall clock 换算，息屏、切后台、退进程都不影响真实秒数；
- 运行时前台服务常驻**系统计时器样式通知**，退后台兜底落库；
- **到达每日目标的提醒**：响铃与震动时长各自可在 **1–20 秒**内调节（循环响铃 + 波形震动）；
- 提醒由 **AlarmManager 精确闹钟**兜底：即使应用被系统冻结或进程被杀，也会在目标时刻准点提醒。

### 📆 导出到日历（.ics）

- 长按计划卡 → **导出到日历（.ics）**：生成一个标准 iCalendar 文件，用系统日历、Google 日历或 Outlook 打开即可导入；
- **旅游规划也能导出**：行程库（🧳 → 行程列表）里每条行程有 📅 导出按钮，生成**一个覆盖整段日期的整天事件**（不按天重复），描述里写备注与「西安北 → 兵马俑 → 回民街」这样的路线；没设日期的行程退化成今天一天；
- 计划会变成**每天重复的整天事件**（`DTSTART;VALUE=DATE` + `RRULE:FREQ=DAILY;UNTIL=截止日`），一个事件覆盖整段，日历里不会塞满 N 条；
- 事件标题带每日目标（`写作 · 每天 30 分钟`），描述里写备注与总天数，`TRANSP:TRANSPARENT` 让同事看到的是「空闲」而不是「忙碌」；
- **不申请任何日历权限、不联网**：只生成文件，导入与否完全由你决定；同一计划重复导入不会产生两条（UID 固定为 `focuslist-plan-<id>`）；
- 实现细节都在 `util/Ics.kt`：CRLF 换行、**75 字节折行**（中文按 UTF-8 三字节算，不能按字符切）、逗号 / 分号 / 反斜杠 / 换行转义——这三条是各家客户端解析失败的常见原因，全部有单测钉住。

### 🔥 计划投入统计：点开卡片看节奏

- **点任意计划卡**（非管理模式）直接打开投入统计：今天做了多少、这几天稳不稳、一共积累了多少；
- 顶部是**今日进度条**，下面一句「今天还差 8 分钟达标 / 今天超出目标 10 分钟」；
- 三个关键数字：**连续达标**、**最长连续**（回溯 90 天，可能长于展示窗口）、**达标率**；
- **最近 14 天柱状图**：柱子按当天目标归一化，达标满格实心、未达标淡化、空白日留一个短横；点任意柱子看「11月3日 · 45 分钟 · 达标」；
- 口径克制：窗口只统计**计划有效期内**的日子，计划还没开始就是空态，不会一上来显示 0%；
- **计划结束后**窗口自动锚到最后一天，仍能看到它收尾时的 14 天，而不是一片空白；
- 连续达标沿用应用内其它地方的约定：**今天还没达标时从昨天往回数**，但计划已结束就不再宽容（最后一天没达标就是 0）；
- 长按计划卡的菜单里也加了「查看投入统计」，入口不止一个。
- **卡上就能看见欠账**：今天的计划卡如果整体落后，标题下方会出现一枚 `落后 2 天` 的白色小角标；按节奏推进、超前、刚开始都不显示——**只有落后才出现**，所以它一出现就值得看一眼；
- **整体进度**：弹层顶部把「时间过了多少」与「目标完成多少」放在一起比——一条投入进度条 + 一根时间刻度线，柱子落在刻度线左边就是落后；
- 结论直接说人话：`落后约 5 天，需要加把劲` / `比时间进度快 12%` / `按节奏推进中` / `刚开始，先跑几天再看节奏`（3 天内不评价，避免第一天就打击人）；
- 还会算出**按时完成每天需要多少分钟**：`还剩 8 天，每天需 42 分钟才能按时完成`；最后一天不再说「还剩 0 天」，改成「今天是最后一天，还需 42 分钟」；
- 口径：总天数含首尾、已过天数含今天、目标总量 = 总天数 × 每日目标；落后天数**向上取整**，差 1 分钟也算落后 1 天。

- 轮换只依赖「周起点距 1970 年有多少周」，同一周在任何设备上算出来都一样，所以**没有额外存储来存进度**：周一进度自然归零；
- 卡片右上角写「剩 N 天」，最后两天换成提示色；完成的挑战打勾并写入成就存储（幂等），换机后仍能在备份里看到「哪一周完成过什么」；
- 底部一句 `本周 2/3 个挑战完成`，全部完成时变成「本周挑战全部完成，漂亮」。



### 🎓 结业的计划：到期给它一个交代

- 计划到期后原本是**一声不响消失**的——首页看不到、也没有任何提示，很容易以为数据丢了；
- 统计页底部因此多了一张「结业的计划」卡：**最近 30 天结束**的计划，最多列 3 个，按结束日从近到远；
- 每个都有一张成绩单：`完成度 78%，只差一点点` + `共 30 天 · 累计 12 小时`。评语只按完成度分档，不评判努力程度（0% 也会说「计划曾经被你认真安排过」）；
- **再来一版**：同配置从今天重新起算、天数不变，同时**把旧的一版归档**——否则结业列表里会一直挂着它；
- **归档**：不想继续了就收进归档，首页与结业列表都不再出现；
- 没有已结束的计划时整张卡不渲染，统计页保持干净。

### ⚙️ 我的：一行一个入口，点进去再改

设置项变多以后，全部铺在一页里会变成一个超长表单。现在「我的」只留入口：**外观 / 每日目标 / 提醒 / 计划模板 / 悬浮胶囊 / 地图与搜索 / 数据备份** 各占一行，每行是「emoji + 名称 + 当前状态摘要 + ›」，不点进去也能看出现在是什么配置（例如「跟随系统 · 滴答蓝」「3 天前备份 · 良好」「高德 Key 已配置」）；点进去是独立的设置页，顶部有返回箭头，只放这一组控件。**统计类入口不放在设置里**：日历主页右上角是「计划统计」，专注页右上角是「专注统计」，各自和数据源待在一起，打开即见。设置页底部只留一行指路文案，最下面是「关于」。

### 📊 计划总览：统计日历里的计划，不是番茄专注

- 入口：**日历主页右上角统计按钮**（Insights 图标，日历展开时显示）；数据源是 `plan_logs`（日历格子、日卡片进度条背后的那份数据），和专注统计用的番茄记录**完全分开**；
- 今日 / 本周 / 本月 / 累计投入四宫格，附活跃天数、达标天数、最长连续、最佳单日；
- **本月计划日历**：7 列周一起始，按当天全部计划的合计投入分五档着色（对照每日目标），今天描边，底部带色阶图例；点开「计划节奏」还能看 6 周计划时间轴与到期计划的结业成绩单；
- **近 14 天柱状图**：达到每日目标当天为实心柱，其余淡化；**各计划投入排行**用计划自己的主题色画占比；
- 计算逻辑放在纯 JVM 工具 `PlanStats`（先按天累加秒再换算分钟，避免多个计划各不足 1 分钟被逐个取整抹成 0），单测 13 条；
- 计划节奏（6 周时间轴 / 结业的计划）从**计划总览页底部**进入；专注统计页里自带月度回顾卡与成就殿堂奖杯入口，所以设置页删掉那三个入口后整条统计链依然可达，不会变成孤岛。

### 🔑 高德 Key：编辑与确定分开

「我的 → 地图与搜索」里的 Key 改成**显式保存**：默认只读展示打码后的已保存值（只留后 4 位便于核对），点「编辑」才进输入态，点「确定」才真正写入本机偏好并回显「✓ 已保存，下次搜索立即生效」；「取消」丢弃草稿，留空并确定则清空。不会再出现「边打字边悄悄存、用户不知道存没存」。

### 💾 数据备份与恢复

- 一键**导出**：把计划、投入记录、番茄记录、任务、习惯、备注与附件、**旅游行程（含站点、交通、路线折线与卡片摆放/叠放顺序）**，外加**偏好设置**、**计划模板**与**成就解锁记录**，整体写成一个 JSON 文件（系统「另存为」选择保存位置，文件名自动带日期）；
- 一键**导入**：选一个备份文件后先预览摘要，再选**覆盖导入**（清空本机后写入，结果等同于备份，并还原设置、模板、行程与徽章）或**合并导入**（保留本机数据与设置，仅覆盖相同 ID 的记录，补充本机没有的模板与**尚未解锁的徽章**，导入结果会告诉你有几枚徽章被补充）；
- 整个导出 / 导入的数据库部分都在**单个事务**内完成，要么整体成功要么整体回滚；
- **备份体检**：我的 → 数据备份，页首卡片显示「上次备份在 N 天前」与距 30 天提醒线的进度条，从未备份或临近 / 超过提醒线时给出导出建议；
- 备份文件带 `schemaVersion`（当前 4），版本不兼容时明确拒绝而不是写入脏数据；旧版本备份仍可导入（缺少的设置、模板、成就与行程自动跳过，本机徽章不会被清空）；
- 走系统文件选择器（SAF），**不需要任何存储权限**，文件始终由你自己保管。

## 架构

```mermaid
flowchart LR
    UI["Compose UI<br/>日历 / 专注 / 习惯 / 我的"] --> VM["ViewModel<br/>Home / Settings / Habits"]
    VM --> REPO["Repository<br/>Plan / Note / Habit / Task ..."]
    REPO --> DB[("Room<br/>focus_list.db")]
    VM --> PREF[("DataStore<br/>设置与偏好")]
    SVC["前台 Service<br/>番茄钟 / 计划秒表"] --> HOLDER["全局状态 Holder<br/>TimerStateHolder<br/>PlanTimerHolder"]
    HOLDER --> UI
    SVC --> CAPSULE["悬浮胶囊<br/>TimerCapsule"]
    SVC --> ALARM["精确闹钟<br/>PlanGoalAlarms"]
    ALARM --> RECEIVER["PlanGoalReceiver<br/>响铃 + 通知"]
    SVC --> NOTIFY["通知 / 提醒"]
```

- **手动依赖注入**：`AppContainer` 按需 lazily 提供数据库、各仓库与设置存储；
- **全局计时状态**用单例 Holder（`StateFlow`）承载，界面、胶囊与桌面小组件都从同一处读；
- **数据库版本**：v1 任务/习惯 → v2 标签与软删除 → v3 计划与备注 → v4 备注标题/日期与附件表，升级走手写 `Migration` 保留旧数据。

## 构建与运行

环境要求：**JDK 17** + **Android SDK 34**（无需 Android Studio 也可以命令行打包）。

### 一键打包（推荐）

双击 `build.bat`，按提示操作：

1. **选择操作**：`1` 开发包 Debug（可调试，自测用）/ `2` 生产包 Release（分发用）/ `3` 运行单元测试（不打包）；
2. **输入版本号**：如 `1.0.53`，直接回车则沿用当前 `version.properties` 中的版本；
3. 脚本自动写入版本号并开始构建，结束后打印 APK 路径与 `adb install` 命令。

也可以命令行非交互执行（便于脚本化）：

```bash
build.bat debug 1.0.53
build.bat release 1.1.0
build.bat test              # 只跑单元测试
```

产物：

| 包类型 | 路径 |
| --- | --- |
| 开发包 | `app/build/outputs/apk/debug/app-debug.apk` |
| 生产包 | `app/build/outputs/apk/release/app-release.apk` |

> `versionCode` 每次打包后自动 +1，`versionName` 保留你输入的值。

### 正式签名

在根目录放 `keystore.properties`（字段见 `keystore.properties.example`）即可启用正式签名；
**没有该文件时 Release 会自动回退到 debug 签名**，保证产出的 APK 可直接安装（但不适合上架应用市场）。

### 直接使用 Gradle

```bash
./gradlew assembleDebug
./gradlew assembleRelease
```

## 数据与隐私

- 计划、专注、备注、习惯、任务与**行程**全部保存在应用私有目录：Room 数据库 `focus_list.db` + DataStore，**不上传、不登录**；
- 联网只发生在旅游规划页：地图底图向高德瓦片服务请求当前视野内的瓦片，真实道路路线向 OSRM 请求两点的折线；请求里不包含账号、设备标识或其它记录，行程本身也不会上传；
- 断网时行程、停留与交通仍可编辑，底图退化成纸面网格，路线退化成弧线示意；联网后自动补真实折线并写进本地数据库；
- 备份导出 / 导入走系统文件选择器，文件保存在你自己选的位置，**不申请任何存储权限**，应用也不会读写备份之外的文件；
- 申请的权限都与功能直接相关：

| 权限 | 用途 |
| --- | --- |
| `INTERNET` | 旅游规划：加载地图底图、获取真实道路路线 |
| `POST_NOTIFICATIONS` | 任务到期、计时结束提醒 |
| `SCHEDULE_EXACT_ALARM` | 到达目标的准点提醒（Android 12+ 需用户允许） |
| `RECEIVE_BOOT_COMPLETED` | 重启后恢复提醒 |
| `FOREGROUND_SERVICE(_SPECIAL_USE)` | 番茄钟与计划秒表后台计时 |
| `VIBRATE` | 结束提醒震动 |
| `SYSTEM_ALERT_WINDOW` | 后台悬浮计时胶囊（可选，用户手动授权） |

## 已知限制

- 旅游规划的**地图底图与真实道路路线需要联网**：断网时底图退化成纸面网格，公交 / 自驾 / 骑行 / 步行退化成弧线示意，行程本身仍可编辑；
- 真实路线默认走 OSRM 官方演示服务，可能限流或在部分网络下不可达；可在 **行程库 → 真实路线服务** 里改成自建 / 镜像 OSRM 地址；
- 内置目的地约 250 个，不是全量 POI 库；清单里没有的地方用「地图选点」或长按地图落点，任意坐标都能加入行程；
- 底图为高德瓦片（GCJ-02），境内会自动纠偏；境外区域高德数据较粗，精确到街道的规划建议仍以当地地图为准；
- ColorOS / 部分国产系统的**灵动岛（流体云）不向第三方应用开放**，胶囊通过系统悬浮窗实现，需要「显示在其他应用上层」权限；
- 悬浮胶囊依赖前台服务存活，若系统激进冻结应用需在设置中允许「后台运行 / 自启动」；**准点提醒不受影响**（由 AlarmManager 唤醒）；
- 胶囊位置以像素记录，横竖屏切换后可能略偏移，可在设置页「重置胶囊位置」；
- 成就解锁记录只在 **schema 3 及以上**的备份里；用更早版本导出的备份做覆盖导入时，徽章会保留本机记录，不会因为「结果等同于备份」而被清空。

- 提示音为程序化合成（正弦波 + 包络），不含第三方录音素材；横幅、界面预览图由 `docs/images/gen_mockups.py` 生成；
- 启动图标为矢量自适应图标「**日轮**」：近黑纯色底 + 一个暖白粗线圆角框（一页日历 /「日」字外框）+ 中间一颗暖橙实心圆（今天的太阳）。按 GPT / X 那类图标的范式做的——纯色高对比、单个几何符号、大留白，不画界面缩略图、不用渐变、不塞细节；符号主体 42dp，在 66dp 可见区里约占六成，48dp 桌面尺寸下靠剪影识别；
